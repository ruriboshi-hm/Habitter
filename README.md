## 概要
推しに応援してもらう気分を味わえる習慣管理アプリ。

## 開発のきっかけ
推し活へのエネルギーやモチベーションを他の行動にも活かせるのではないかと考えたことがきっかけです。
そこで、モチベーション維持が課題となる習慣化を組み合わせた「推し活×習慣化」アプリとして開発を始めました。
以前、KotlinでTODOリストアプリを制作した経験があったため、それを活かして、Kotlinを用いたAndroidアプリとして制作しました。

## 開発環境/技術選定理由
* Kotlin：Javaよりも簡潔にコードを書けることから、継続的な運用に適していると考えたから。
* Realm：記録系アプリのためオフラインで使う場面が多いと考えたから。またSQLiteよりも高速なため選択。
* AndroidStudio：主要な開発環境で、Android開発に必要なツールがすべて統合されているかつテストがしやすいことから選んだ。

## 機能
* 習慣画面：習慣を完了するとプログレスバーに色がつきます。
* 習慣追加/編集画面：習慣の名前、リマインダー、アイコンなどを選択する画面。
* 習慣一覧：各習慣の完了状況を確認できます。未完了の習慣を絞り込み表示することもできるようにしました。

## 工夫した点
* 推し要素・カスタマイズ性：アイコン画像・通知・完了後のメッセージ・テーマカラーなど、ユーザーがカスタマイズできる要素を増やし、楽しみながら習慣を続けられるようにしました。
* シンプルな操作：ワンタップで習慣を記録でき、自動でカレンダーに反映されるようにしました。操作をシンプルにすることで、習慣化の心理的なハードルを下げています。
